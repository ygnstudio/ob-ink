# ob-ink

Obsidian 极简 CSS 片段集：整页只留一支主题色，其余全是墨。不装主题、不依赖插件，复制进 `snippets` 目录、开关一开就生效，每件头部有中文可改区，改个数字保存即见效。

## 片段清单

| 片段 | 作用 |
|------|------|
| `0-核心-颜色地基` | 全套颜色的唯一出处：墨色四档、主题色、卡片底、高亮、发丝线。其他片段都引用这里 |
| `1-功能-状态栏隐藏` | 隐藏底部状态栏 |
| `2-美化-正文` | 标题层级、加粗斜体、高亮、列表、脚注、标签、行距节奏 |
| `2-美化-代码样式` | 行内代码胶囊 + GitHub 色板代码块（浅色深色两套） |
| `2-美化-卡片族` | Callout 标注卡、表格、嵌入、Mermaid 统一为同一族卡面 |
| `2-美化-半透明界面` | 开启系统半透明窗口后的窗口垫层，深浅两档可调 |
| `2-美化-文件列表高亮` | 左侧文件列表选中项提亮 |
| `2-美化-标签页胶囊款` | 页签胶囊化（与描边款二选一） |
| `2-美化-标签页描边款` | 页签描边化（与胶囊款二选一） |

## 使用

1. 把 `snippets/` 里的文件复制到你的库：`设置 → 外观 → CSS 片段 → 文件夹图标` 打开的就是目标目录
2. 回到 `设置 → 外观 → CSS 片段`，逐件开启，即时生效
3. 建议全开（标签页胶囊款 / 描边款二选一）；`0-核心-颜色地基` 是地基，其他片段的颜色都出自它

## 可改区

每件片段开头集中了所有可调项，中文注释标明单位与方向（越大越浓 / 越透）：

```css
/* ── 可改区 ────────────────────────── */
/* 高亮浓度：0–100，越大越艳 */
--ct-mark-bg: 26%;
```

改数字 → ⌘S 保存 → 页面立刻变，不用重启。想换风格改两处就够：`0-核心-颜色地基` 换整套颜色的浓淡，`设置 → 外观 → 主题色` 换全页唯一的彩色。

字号、主题色这类核心已有的设置不重复造：字号在 `设置 → 外观 → 字体大小`，主题色在 `设置 → 外观 → 主题色`。

## 设计约定

- **颜色只留一支**：全页只有主题色一处彩色，其余用墨色深浅分层，深浅色模式各自成套。墨：指非彩色的文字色阶——黑与灰的深浅分层（正文、次级、次要、最弱四档），主题色是全页唯一的彩色
- **只用核心变量**：颜色全部取自 Obsidian 原生变量（`--text-normal`、`--interactive-accent` 等）再调和，换主题色全页联动，不硬编码色值
- **减法优先**：能靠留白和字重解决的不加颜色，能一条规则解决的不写两条

## 已知限制

- `2-美化-半透明界面` 需要系统 `设置 → 外观 → 半透明窗口` 开启才有效果
- `2-美化-正文` 里的中西文空格规则（`text-autospace: normal`）是功能本体——Obsidian 核心默认关闭自动空格，删掉它段内中西文之间就不留空了
- 标签页胶囊款与描边款互斥，同开以后开的为准
